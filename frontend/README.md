# USP Shop — Frontend

Next.js (App Router) application. See the [repository root README](../README.md) for the full project overview.

## Running

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Requires a `.env.local` file with the backend URL:

```
NEXT_PUBLIC_API_URL=http://localhost:8080
```

## Build

```bash
npm run build
```
