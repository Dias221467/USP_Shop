# USP Shop — Frontend

Next.js (App Router) приложение. Подробности всего проекта — в [README корня репозитория](../README.md).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Нужен файл `.env.local` с адресом бэкенда:

```
NEXT_PUBLIC_API_URL=http://localhost:8080
```

## Сборка

```bash
npm run build
```
